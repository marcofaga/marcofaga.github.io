Categorização de Bens de Candidatos com Deep Learning (2006–2022)

Python R BERT Transformer

Projeto de categorização automatizada da base de bens de candidatos(as) nas eleições brasileiras (2006–2022), utilizando NLP e redes neurais para padronizar mais de 4 milhões de registros do TSE. Com fine-tuning do modelo BERTimbau, alcançou 99,3% de acurácia em validação manual.

Mapas Eleitorais com R — Coda.Br 2023

R GIS sf

Workshop ministrado no Coda.Br 2023 com foco na análise e visualização de dados eleitorais georreferenciados utilizando R. Os participantes aprenderam a manipular dados espaciais com os pacotes tidyverse e sf, associando resultados eleitorais a territórios intramunicipais e produzindo mapas temáticos para explorar padrões de votação e geografia política. Material e aulas elaborados em parceria com os pesquisadores Lucas Gelape e João Victor Guedes-Neto.

Extração de Dados Históricos das Eleições Municipais Paulistas (1982–1996)

Python Scrapy WebScrap

Coleta automatizada de dados eleitorais das eleições municipais de São Paulo (1982–1996) a partir do site da Fundação SEADE, utilizando Scrapy em Python. Os dados extraídos foram organizados em arquivos estruturados para prefeito e vereador, com inclusão de códigos IBGE e TSE e dicionário de variáveis para facilitar a análise.

Captação e Análise de Dados Eleitorais com R

R

Aula prática de introdução ao R aplicada à análise de dados eleitorais, com foco na eleição presidencial de 2014. Os alunos aprenderam a importar, tratar, visualizar e cruzar dados do TSE com indicadores socioeconômicos, aplicando filtros, agregações e análise estatística.
